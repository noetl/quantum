## Competition

| Term | Meaning |
| --- | --- |
| Ancilla | A scratch qubit returned to `\|0>` after use. |
| Block encoding | A unitary that contains `H/λ` as a sub-block. dfthcsos prices one. |
| Clifford | Gates generated by H, S, and CNOT. Cheap, and classically simulable. Cancelling them does not move the VQCC task costs. |
| Charged weight | The static count the optimize step uses to decide whether a file is worth a verifier call. invsqrt charges Toffolis, T gates, and fine rotations. dqi and dfthcsos charge Toffolis. `Q` is a separate veto. |
| DQI | Decoded Quantum Interferometry. In this competition, the kickmix piece is a coherent Reed–Solomon decoder over `GF(2^12)`. |
| `E_gap`, `Λ` | Inputs to dfthcsos `lambda_eff`. Hub: product `E_gap * (2Λ − E_gap)`. Paper equation 44, and the README captured in the version 8 log: the square root of that product. FR-007 is open. |
| Fail-closed | Keep a candidate only when the official verifier returns `PASS` and a strictly lower JSON `score`. Anything else leaves the previous artifact in place. |
| `GF(2^m)` | Finite field with `2^m` elements. Addition is XOR. |
| kickmix | Circuit tool and simulator. Files are `.kmb` (binary) and `.kmx` (text). PyPI `kickmix==1.0.0` is the public package. `kickmix.so` on the Kaggle image is a different binary and is not committed. |
| `lambda_eff` | dfthcsos score multiplier. Printed baseline `49.301369250574396`. Definition is FR-007. |
| Lower is better | Direction of each task's JSON `score`. The hub's three-task mean, if confirmed, would point the other way. That mean is FR-008 and is not `leaderboard_score`. |
| mHa | Milli-Hartree. dfthcsos rejects an encoding more than 20 mHa off. |
| `Q` | Qubit count. A multiplier in every task cost, and squared in the dqi cost. |
| `R(ε)` | dqi repetition factor. Printed baseline `1.1912604648115832`. Algebraic form is FR-006. |
| Salt | Secret mixed into the verifier seed so the test inputs depend on the file. A local seed, including `20261108`, is not the leaderboard salt. |
| T / Toffoli | Non-Clifford counts that dominate the cost. The paper's dqi `T` is a Toffoli count. The hub's `T` is not given that sentence. |
| THC | Tensor hypercontraction, a low-rank factorization of the two-electron tensor. |
| Uncomputation | Erasing garbage so the computation stays coherent. Measurement uncompute (`HMR` plus a conditional `CZ`) is kickmix `del_and`. |

## This repository

| Term | Meaning |
| --- | --- |
| Ancestor check | The notebook refuses to score a checkout unless a known merge commit is an ancestor of `HEAD`. Version 8 required `ecb0f601`, the merge of PR #12. |
| Authoritative cost | `cost_authoritative: true`. Official script, exit 0, one JSON object, `status` `PASS`, finite `score` > 0, dataset not marked `.vqcc-fixture`. |
| Baseline | The reference sample, or the last retained artifact. Not an optimized candidate. |
| `leaderboard_score` | The playbook's final field for a Kaggle leaderboard return. It is null on every run this tutorial cites. |
| NoETL playbook | A YAML workflow, `apiVersion: noetl.io/v2`, executed by `noetl run --runtime local`. |
| Provenance | `runs/<id>/provenance.json`. Git-ignored. Holds hashes, verifier status, and costs. It is not a row in `docs/experiments.md`. |
| Structural fixture | A kickmix file this repo builds when `mode=structural`. Labeled so it cannot count as competition-verified. |
| `structure` | Profile logged by the optimize step: opcodes, lifetimes, peak live qubits, repeated blocks. Not a score. |
| US1 … US5 | User Story 1 through User Story 5 in `specs/001-noetl-pipeline/spec.md`. |
| Version 9 | The Kaggle run of main `da8490e` on the private notebook, scriptVersionId `368976547`, run `20261113T015716Z-fea5b448`. The measured outcome is in [Optimization history](Tutorial-06-History). |
