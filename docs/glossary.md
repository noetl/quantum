# Glossary

Definitions from the team hub, plus a few terms the paper uses for the same
objects. Nothing here is a measured result.

| Term | Meaning |
| --- | --- |
| Ancilla | A scratch qubit returned to `\|0⟩` after use. |
| Block encoding | A unitary that contains `H/λ` as a sub-block. |
| Clifford group | Gates generated by H, S, and CNOT. Cheap, and classically simulable. |
| DQI | Decoded Quantum Interferometry, an optimization algorithm that uses a decoder. |
| `E_gap`, `Λ` | Parameters in the dfthcsos cost. Hub: `λ_eff = E_gap(2Λ − E_gap)`. Paper equation 44 takes the square root of that product. |
| `GF(2^m)` | Finite field with `2^m` elements. Addition is XOR. |
| kickmix | The competition verifier and circuit tool (`kickmix.so`). Circuits are stored as `.kmb` / `.kmx`. The paper describes kickmix circuits as reversible classical gates, diagonal phases, and measurement-based uncomputation, so a classical simulator can run one input in time linear in the gate count. |
| LCU | Linear combination of unitaries. |
| mHa | Milli-Hartree. The dfthcsos tolerance is 20 mHa. |
| `Q` | Qubit count. A multiplier in every task cost, and squared in the dqi cost. |
| `R(ε⁺)` | Repetition overhead from an approximate decoder. The algebraic form is **unconfirmed (hub)**. See the dqi section of [brief.md](brief.md). |
| T-count / Toffoli count | Number of non-Clifford gates. These dominate fault-tolerant cost. The paper's dqi `T` is a Toffoli count. The hub's `T` is not given that sentence. |
| THC | Tensor hypercontraction, a low-rank factorization of the two-electron tensor. |
| Uncomputation | Erasing garbage registers so the computation stays coherent. |
| `.kmb` / `.kmx` | kickmix circuit files. The paper describes `.kmb` as a binary struct-of-arrays serialization. |
| Salt | A secret mixed into the hash of the submitted circuit so the fuzz-test inputs change with the file and cannot be ground in public. Hub wording: submission hash plus a secret salt. Paper: SHA-256 of the bytes, combined with a private salt. |
